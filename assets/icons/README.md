# wmcterm application icon

These application icon files are based on the icon from
`/media/wangxh/DATA/code/wmcssh/src-tauri/icons`, with a more rounded green
frame and a transparent area outside the frame.

- `icon.png`, `128x128.png`, `256x256.png`: runtime/package PNG assets
- `icon.ico`: multi-resolution Windows executable icon (16 through 256 px)
